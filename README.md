# My Page Web

Página web básica construida para poner en práctica la integración de los tres pilares del desarrollo web frontend: **HTML5** para la estructura, **CSS3** para los estilos y **JavaScript** para la interactividad.

---

## 🚀 Características

- **Estructura Limpia:** Marcado HTML sencillo y semántico.
- **Diseño Oscuro (Dark Theme):** Estilos aplicados con CSS para un fondo oscuro moderno y tipografía centrada.
- **Interactividad Básica:** Un botón que ejecuta una función de saludo mediante una ventana emergente (`alert`) en JavaScript.
